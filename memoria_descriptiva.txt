   +----------------------+       +----------------------------------------------+
   | INTERFAZ             |       | MOTOR DE INFERENCIA (motor_inferencia.py)    |
   | (interfaz.py)        | ----> | 1. Recuperar   similitud ponderada, k = 3    |

   | Nuevo ticket, Base,  | <---- | 3. Revisar     técnico + conformidad         |

   +----------------------+       +----------------------+-----------------------+
                                                         |  lee y escribe JSON
                                  +----------------------v-----------------------+
                                  | BASE DE CONOCIMIENTOS (base_conocimientos/)  |
                                  | casos, catálogo, categorías, similitud y     |
                                  | parámetros, reglas, estructura, fuentes      |
                                  +----------------------------------------------+

Los cuatro contenedores de conocimiento de un sistema basado en casos (López de Mántaras
et al., 2005) son el vocabulario (catálogo de síntomas y árbol de categorías), la medida de
similitud, la base de casos y el conocimiento de adaptación (reglas). Cada uno está en su
propio archivo JSON.

============================================================================================
3. INTERFAZ DE USUARIO (pestañas)
============================================================================================

  - Inicio: qué hace el sistema, cómo razona, cómo se validó la base y todas las fuentes
    utilizadas.
  - Manual de uso: guía paso a paso antes de usar el sistema y problemas frecuentes.
  - Nuevo ticket: registro del ticket (con botón «Cargar ejemplo»), los 3 casos más
    parecidos, su respaldo, la solución propuesta, la justificación completa y la revisión
    del técnico.
  - Base de casos: tabla filtrable y detalle de cada caso con sus fuentes y fragmentos
    literales.
  - Administrar (requiere clave): agregar caso, validar pendientes, agregar fuente y agregar
    síntoma.
  - Validación: validación dejando un caso fuera, casos de prueba, análisis de sensibilidad,
    auditoría de coherencia y verificación de la base.
  - Fuentes: preguntas y respuestas con fuentes, matriz de trazabilidad y listas de fuentes.

4.1 Recursos informáticos y librerías
-------------------------------------
Software necesario
  - Python 3.9 o superior (probado con 3.11 y 3.13), con pip, su gestor de paquetes.
  - Streamlit 1.40 o superior (probado con 1.65): es la única librería externa del proyecto
    (requirements.txt) y solo la usa la interfaz. Al instalarla, pip descarga también sus
    dependencias (por ejemplo pandas, NumPy, PyArrow y Altair); el proyecto no las importa
    directamente.
  - Navegador web actualizado (Chrome, Edge o Firefox) para abrir la interfaz en
    http://localhost:8501.
  - Sistema operativo: Windows 10 u 11 (con ejecutar.bat) o cualquier sistema con Python 3.9
    o superior, ejecutando los comandos desde una terminal.

Biblioteca estándar de Python (viene con Python, no se instala)
  - motor_inferencia.py:
      json ................ lee y escribe la base de conocimientos y los casos de prueba
      hashlib, hmac ....... huella SHA-256 de la clave y comparación en tiempo constante
      tempfile, os ........ escritura atómica de los JSON (archivo temporal y reemplazo)
      dataclasses ......... estructuras Caso, Consulta y Resultado
      pathlib ............. rutas de las carpetas base_conocimientos/ y validacion/
      re .................. sustitución de comandos entre Windows y Ubuntu (regla R1)
      datetime ............ fecha de los casos retenidos
      itertools ........... combinaciones de la auditoría y del análisis de sensibilidad
      sys ................. opciones de consola (--validar, --pruebas, etc.)
  - interfaz.py (además de Streamlit, que dibuja pestañas, formularios, tablas y botones):
      html ................ escapa los textos que se muestran en la interfaz
      json, re, sys,
      pathlib ............. lectura de archivos y rutas del proyecto

Archivos de configuración
  - requirements.txt ........ dependencia del proyecto (streamlit>=1.40)
  - ejecutar.bat ............ instala la dependencia y abre la interfaz en Windows
  - .streamlit/config.toml .. colores del tema; desactiva el envío de estadísticas de uso

Recursos de red (opcionales)
  - Conexión a internet solo para instalar Streamlit la primera vez.
  - La interfaz carga sus tipos de letra e íconos desde Google Fonts (Bricolage Grotesque,
    Figtree, JetBrains Mono y Material Symbols Rounded). Sin conexión funciona igual, con
    las fuentes del sistema; algunos íconos pueden verse como texto.

Equipo
  - No requiere hardware especial: la base de conocimientos ocupa menos de 1 MB y la
    validación, los casos de prueba, la auditoría y el análisis de sensibilidad se
    ejecutan en menos de un segundo cada uno.
  - No usa base de datos ni servidor externo: todo se guarda en los archivos JSON del
    proyecto.

4.2 Instalación y ejecución
---------------------------
Requisitos: Python 3.9 o superior (marcar «Add Python to PATH» al instalarlo) y la carpeta
completa del proyecto.

Opción A – Windows: doble clic en ejecutar.bat (instala Streamlit la primera vez y abre el
navegador).

Opción B – terminal, dentro de la carpeta del proyecto:
    pip install -r requirements.txt
    streamlit run interfaz.py            (si falla: python -m streamlit run interfaz.py)
Se abre http://localhost:8501. Para cerrar: Ctrl + C en la terminal.

Motor por consola (sin interfaz, solo biblioteca estándar):
    python motor_inferencia.py                 ejemplo + validación
    python motor_inferencia.py --validar       validación dejando un caso fuera
    python motor_inferencia.py --verificar     verificación de la base
    python motor_inferencia.py --pruebas       casos de prueba
    python motor_inferencia.py --auditar       auditoría de coherencia
    python motor_inferencia.py --sensibilidad  análisis de sensibilidad
